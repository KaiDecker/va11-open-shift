# Fusion Pixel font source

The launcher bundles **Fusion Pixel 12px Proportional Zh_hans** as a WOFF2 web
font. Fusion Pixel is an open-source pixel font by TakWolf, distributed under
the SIL Open Font License 1.1:

<https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.08.11>

Source asset:
`fusion-pixel-font-12px-proportional-ttf.woff2-v2026.08.11.zip`

SHA-256 of the upstream asset: `5b8b7acc4ac2f25ea0406182bc80de000c5c6388a0b59e13ea7414eb992e32d4`

SHA-256 of the bundled webfont:
`4e2e29830c8b4e0f19bf7b6f01f1fa7347c48dab9418824a2a289919d4a8c748`

The player package does not extract or redistribute the original VA-11 HALL-A
font.
