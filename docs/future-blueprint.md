# OPEN SHIFT 后续蓝图

## 近期原则

先保证原版链路、存档安全和可诊断性，再扩大生成内容。任何新功能都必须有确定性回退、
幂等提交和可复现日志，不以牺牲 Steam 原版安全换取便利。

## Agent 方向

角色拥有独立、可迁移的记忆、目标、关系和有限视角，但只能通过规则层影响权威世界。记忆
会记录来源和确信程度，并通过有界检索进入对白提示；低价值重复内容可归档，未解决事项和
承诺必须保留。自由文本
不能直接创建金钱、事件或剧情分支；所有可见结果都要落入可测试的 schema。

## 社区方向

公开版本优先收集安装问题、原版流程偏差、对白自然度和性能数据。贡献者应提交最小复现、
脱敏日志和测试；参考游戏内容只用于分析流程与风格，不直接分发原版资源或大段台词。
