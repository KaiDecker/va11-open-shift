# OPEN SHIFT v0.24.0-preview.5

这是 OPEN SHIFT 的 Windows x64 公开预览版。它把启动器改成了更接近《VA-11 HALL-A》原版的像素风界面，并修复了上一版可能导致游戏一直等待世界状态的问题。

## 这版有什么变化

- 启动器使用黑底、深紫色硬边框和像素字体；
- 修复本地运行配置的读取路径，游戏可以正确连接已启动的本地服务；
- 每个版本独立保存数据库、日志、配置、API Key 和配套存档；
- 修复 O.S. DAY2 及以后在房间保存后，重启并直接使用原版“读取”会回到 DAY1 的问题；
- 支持快速、平衡和深度三档 DeepSeek 生成模式；
- 提供日志查看、诊断导出、检查更新和安装修复入口；
- 使用轻量安装方式，不再复制完整 Steam 游戏目录。

## 开始之前

- 需要正版 Steam Windows 版《VA-11 HALL-A》；
- 需要自己的 DeepSeek API Key；
- 需要系统安装 Microsoft Edge WebView2 Evergreen Runtime；
- 当前只支持 Windows x64，仍属于公开预览版。

## 包里有什么

玩家压缩包只包含启动器、运行程序、安装脚本、WebView2 Loader、像素字体和增量补丁。它不包含：

- UTMT 或 `UndertaleModCli.exe`；
- 完整的原版 `data.win` 或游戏 EXE；
- Python/GML 源码；
- API Key、数据库、存档、日志或验收截图。

安装器会读取你本机正版游戏的 `data.win`，应用包内补丁，并在独立目录创建 OPEN SHIFT 实例。Steam 原版目录不会作为写入目标。

## 关于旧版本

原帖中的 `v0.19.0-rc.23` 已经过时，不建议继续使用。请以本版本及其 GitHub Release 附件为准。

请在 GitHub 提交 Issue，并附上版本号、生成模式、复现步骤以及脱敏后的 `timing.log`、`dialogue.log` 或 `launcher.log`。不要上传 API Key、数据库、存档或原版 `data.win`。
