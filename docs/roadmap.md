# OPEN SHIFT 路线图

## 阶段 20：首个公开预览版（已完成）

- 全面更新公开文档、安装说明、贡献指南和发布清单；
- 增加可重复的自动检查与发布包审计；
- 完成全新用户安装、连续两天、保存/读档、卸载和 Steam 原版哈希验收；
- 发布 Windows x64 Preview，并邀请 Issue 和 PR。

## 阶段 21：原版风格与对话质量（已完成）

- 建立角色事实、关系和语气约束；
- 使用原版流程节奏作为结构参考，避免角色身份和语气错误；
- 增加对白自然度、重复内容和立绘连续性检查。

## 阶段 22：Agent 世界深化（已完成）

- 扩展记忆、目标、关系和跨日事件；
- 保持角色信息隔离，避免模型全知；
- 让事件对后续酒吧对白和平板内容产生可追踪影响。

阶段 22 的记忆系统使用 SQLite 内的角色私有记忆。每条记忆标记来源（亲历、听说、传闻、推断）、
可信度、可见性和归档状态；检索只返回当前角色在当前时间点可知且未归档的有限内容。旧数据库会在
启动时自动补齐字段，旧记忆按 legacy 来源读取。日志只记录角色、记忆 ID、来源、检索结果和归档数量，
不记录 API Key、提示词或完整响应。关系、目标、金钱和剧情游标仍由规则层维护，LLM 不能直接修改。

## 阶段 23：轻量安装与版本隔离（进行中）

- 不再复制完整 Steam 游戏目录；实例只保存补丁后的 `data.win`，只读资源使用 Windows 链接；
- 每个安装版本独立保存数据库、日志、配置、API Key 和 OPEN SHIFT 配套存档；原版 GameMaker 存档保持兼容；
- 安装状态记录实例 ID、补丁指纹和链接清单，升级不会误用旧实例；
- 卸载只删除当前实例及其链接，拒绝触碰 Steam 原版目录；
- 默认安装目录按 `PACKAGE_MANIFEST.json` 的版本命名为 `%LOCALAPPDATA%\OpenShift-<package_version>`；
- 同卷文件优先使用 HardLink，目录使用 Junction，跨卷文件使用 SymbolicLink；文件链接权限不足时逐个复制 EXE/DLL 并记录 `copied_file`，目录无法创建 Junction 时明确停止；
- 更新安装说明、玩家包说明和安全回退测试。
- 开发构建阶段使用 UTMT 生成 `patch/data-win.delta`；玩家端只应用带原版/目标 SHA-256
  校验的增量补丁，发行 ZIP 不包含 UTMT 或完整 `data.win`。

## 阶段 24：启动器与社区体验

- 增加更新检查、日志导出、一键修复和版本诊断；
- 改善生成模式、耗时和错误提示；
- 根据社区反馈迭代安装和贡献流程。
